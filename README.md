DOJO - Your Way, Every Day

A web application for tracking daily habits, building consistency, and leveling up through personal progress.

📋 Description

DOJO is a habit-tracking web application designed to help users develop helpful habits and reduce harmful ones.

Users will be able to set personal goals, track daily activities, gain experience points (XP), unlock new levels, and see their DOJO character evolve as they make progress.

The main idea is simple: Improve your habits. Level up your character. Level up yourself.

🛠️ Tech Stack

- Programming Language: JavaScript
- Frontend Styling: CSS
- Backend: JavaScript (framework to be confirmed by the team)
- Database: MongoDB
- Database Modeling: Mongoose
- Version Control: Git, GitHub
- Task Management: Trello
- Design: DOJO UI mockups and design system

✨ Features (Planned)

- User Accounts: Registration, login, and profile management.
- Habit Tracking: Create and manage habits, set goals, and track daily progress.
- Gamification: Earn XP, level up, and evolve the DOJO mascot.
- Progress Overview: View streaks, achievements, and basic statistics.

🔗 Planned API Endpoints

- /api/auth - User registration and authentication
- /api/users - User profile management
- /api/habits - Habit management (CRUD)
- /api/progress - Habit progress and statistics
