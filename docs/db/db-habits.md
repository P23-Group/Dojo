userId | string | уникальный Id пользователя что создал привычку | "fjk123135sdf3adso3"

name | string | Название что вводит пользователь | "Занятся спортом"

category | string | Категория привычки | "Здоровье"/"Обучение"/"Избегать"

type | string | Тип привычки, полезная или нет    |    helpful - полезная привычка, harmful - вредная

trackingFormat |  string | Имеет ли привычка числовое значение, что пользователь отмечает сколько именно он сделал или он просто отмечает как выполнено/не выполнено | (counter - счётчик, yes_no - простая отметка)

goalValue | int | Число для достижения что выставляет пользователь, если включён счётчик и привычка положительна | Например выпить 500 милилитров воды за день, прочесть 5 страниц или заниматься спортом 30 минут. Для вредных привычек значение по умолчанию 0

goalFormat |  string |   Формат измерения привычки, милилитры, количество, время |  Выпить 500 мл воды, заниматься пробежкой 15 минут

frequency | [Number] | Дни недели в которые привычка будет появлятся, хранится как [0,1,2,3,4,5,6] | Каждый день/свой выбор

  "frequency": [0,1,2,3,4,5,6]
},
