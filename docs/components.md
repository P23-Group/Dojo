UI Components - Dojo

1. Sidebar

Назначение: Боковая панель навигации для перехода между основными страницами приложения

Получает данные:

activePage - идентификатор активной страницы
navigationItems - список пунктов навигации с названиями, ссылками и иконками

2. Header

Назначение: Верхняя панель страницы с её названием и дополнительными элементами интерфейса

Получает данные:

title - название текущей страницы
user - информация о текущем пользователе, если она нужна для макета
actions - дополнительные действия или кнопки, если они предусмотрены дизайном

3. HabitRow

Назначение: Отображение одной привычки в списке привычек пользователя

Получает данные:

id - уникальный идентификатор привычки
name - название привычки
completed - статус выполнения привычки за текущий день
onToggle - функция изменения статуса выполнения привычки

4. ProgressRing

Назначение: Круговой индикатор прогресса, который показывает выполнение целей или привычек

Получает данные:

value - текущее значение прогресса
maxValue - максимальное значение прогресса
label - текст внутри индикатора или рядом с ним

5. CharacterCard

Назначение: Карточка персонажа, которая отображает его внешний вид и информацию о прогрессе пользователя

Получает данные:

name - имя или название персонажа
image - изображение персонажа
level - текущий уровень
description - краткое описание или сообщение персонажа

6. Button

Назначение: Универсальная кнопка для подтверждения действий, навигации и взаимодействия с интерфейсом

Получает данные:

label - текст кнопки
variant - тип кнопки, например primary или secondary
disabled - состояние доступности кнопки
onClick - функция, которая выполняется после нажатия

7. Input

Назначение: Поле для ввода текста в формах авторизации, регистрации и добавления привычек

Получает данные:

value - текущее значение поля
placeholder - подсказка для пользователя
type - тип поля, например text или password
label - название поля
onChange - функция обработки изменения значения
error - сообщение об ошибке, если она есть

8. Card

Назначение: Универсальный контейнер для группировки связанного содержимого, например привычек, статистики или информации о пользователе

Получает данные:

title - необязательный заголовок карточки
children - содержимое карточки
variant - вариант оформления, если он предусмотрен дизайн-системой
